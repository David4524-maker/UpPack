# UpPack

UpPack es una app de almacenameinto "en la nube" (La verdad es almacenameinto local), existen 2 versiones:

- main.py (El normal)

- index.html (El simulacion)

## Caracteristicas

- 2 versiones 

- almacenamiento local

- disco propio

> IMPORTANTE: UpPack en inicial ofrece 1GB gratis, si marcas la casilla "Liberar 19GB gratis" en total tienes 20GB (1+19=20), y no hay nube, es disco local (al menos no recopila tus busquedas de Google)
